# Skill Box｜启动 Prompt

## A｜GPTS 迁移

@skill-box A 模式。分析我上传的 GPTS Instructions、Prompt、Knowledge 与旧配置，结合实际可访问的 GitHub 仓库和现行 Plugin/Skill 规范，交付逐文件迁移矩阵、内容迭代方案、仓库资产与 Manifest 路由、能力兼容矩阵及测试方案。先让我核实目标方案；确认后再创建目标 Skill 包并同步已授权的知识资产。

## B｜创建新 Skill

@skill-box B 模式。根据我提供的目标、示例和限制，补足可验证的任务/输入/输出/质量契约；检索官方规范及适用的 GitHub 原始项目，建立最小的 Skill 与按需资产路由，创建、安装并运行代表性测试。业务 Skill 完成后独立运行。

## C｜升级已有 Skill

@skill-box C 模式。依据我上传的 Skill、用户反馈和失败样例，审计触发、输入、GitHub 资产、工具、生成、输出和 QA 链路，给出有证据的根因与逐文件升级方案；按已授权范围修复，并运行旧案例与失败案例的回归测试。
